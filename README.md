## Hi, I'm Abdallah Momen

Computer Engineering student at Ain Shams University in Cairo, and a freelance developer.

**I build automations, bots and web apps that save businesses time.** I also work on distributed systems, computer vision and embedded firmware.

### What I build

- **Python automation:** web scraping, Telegram/WhatsApp bots, Excel and report automation
- **Full-stack web apps:** React frontends with Django or Node.js backends, REST APIs, auth, dashboards
- **Android apps:** Kotlin, MVVM, Room, Retrofit
- **Systems work:** distributed serving and load balancing, OpenCV, FreeRTOS on ARM Cortex-M
